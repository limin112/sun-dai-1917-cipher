# 孙中山“文密”｜Round 11：原始资料入口复核 + 任意私人表恢复法的正对照失败

日期：2026-10-07

目标仅为 JACAR B03050090200：1917-06-24 帧0509、1917-06-29 帧0511。

**状态：六月目标经验证的新明文仍为 0 字；完整密钥仍未找到。六月原图仍未取得。** 本轮没有把任何流畅候选当作译文。

## 1. 本轮真正新增的档案层面结果

爱知大学 2016 年馆藏目录中，旧线索“270 / 整理138 / 24-6”这次做了 PDF 页图核验：该行确为 **胡漢民 → 藤瀬政次郎，1923-02-10，書簡**，备注为：

> 孫中山との間の暗号電報，用法，時間，場所の説明

这比此前只依赖文本抽取更可靠，但仍只是**目录元数据**，不是书简正文，更不是 1917 年六月密钥。爱知大学官方说明称“孫文、山田良政・純三郎関係資料”的微缩胶片版可在大学图书馆阅览；1996 年补遗的检索文本进一步称，上一批书简资料于 1995 年 8 月制成微缩胶片并在丰桥校区图书馆供阅览。本轮仍未得到原书简影像。

JACAR 的 B03050090200 官方元数据可检索，确认该项覆盖 1917-03-29 至 1917-09-21、共 11 图，但六月 0509/0511 原图仍未成功打开，故所有六月字符继续标记为 **image_verified=false**。

## 2. 新算法：把“私人表不是规则表”真正放宽到任意映射

公开研究已指出六月有 y 和非 CV 串，简单系统化 20×5 / 六元音家族都不能读。本轮因此测试一个明显更宽的模型：

1. 只取完整十字母词，从词首按两字母切成符号，不要求 CV。
2. 每个出现过的两字母符号可任意、但一一地映射到 00…99。
3. 相邻两个两位数拼成四位数，再查标准中文电报码。
4. 搜索完全不预设元音、辅音、行列顺序、旋转或加数。

它可以容纳 y 和 `my`、`as`、`fo` 之类非传统 CV 组合，因此不是 Round8 的“两类字母固定换名”重复实验。

## 3. 先做独立正对照，结果：方法失败

训练评分器只用了 1916 年公开已读/部分已读的孙中山相关电报，共 36 段、1256 个汉字；**没有把 1917 年 3 月正对照明文放进训练语料**。

正对照使用 1917-03-25 与 1917-03-26 两份电报。它们有独立已知的 March key：辅音顺序 `klmnpqrstvxyzbcdfghj`，元音 `aeuoi`，vowel-major，offset 1，无加数。

按公开未完全校正的转录直接代入真钥匙，得到的原始译码在干净位置接近已发表明文，在已知抄写/辨读错误处出现乱码。评分约 **-381.814**。

随后做盲搜索：12 次重启 × 每次 60,000 步 simulated annealing，在 51 个已出现两字母符号的任意 00…99 单射表上优化。结果反而找到评分更高的假明文（约 **-307.464**），但与真实密钥只吻合 **1 / 51** 个符号映射。

这说明：**“任意私人表 + 当前短语料语言评分”的搜索会严重过拟合。** 它甚至不能从独立已知题恢复 March key，所以没有资格拿去解释六月。任何由这个算法生成的“看起来像中文”的六月候选都必须丢弃。

这不是对“私人任意表”历史假设的否定；只是否定了当前这套盲恢复方法和评分器在现有数据量下的可识别性。

## 4. 为什么这仍值得保存

这个负结果封住了一条很容易制造假突破的路线：以后不能因为任意表搜索吐出“电、款、覆、日”等高频词就宣布破译。正对照显示，语言模型完全可以把错误密钥拟合得比真钥匙分数更高。

下一轮若继续任意表路线，必须先加入真正的新约束，例如：原图校定字符、同线路更多文密、实际私人码本/书简中的表结构、已知明密对、或能约束码类/字段的历史规则。否则继续扩大随机搜索只是制造更多伪中文。
