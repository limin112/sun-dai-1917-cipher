# Sun Yat-sen / Dai Jitao, June 1917 cryptanalysis research, Round 16

Unzip; from this directory run `python3 round16_analysis.py` (Python 3 stdlib). Every output is a structural observation, never an identified plaintext or codebook.

The old frozen `input/ciphertexts.json` is bytewise from the Round 15 /14 research, SHA-256 `620e469ec26d6534df2dbad0553d79844f1d9df8e68e47a95194a1c0563a8136`. `input/independent_witness.json` holds the separate published independent blind reading of 0509+0511 and pointers to reproductions, not original redistributable scans. Code and this report are new; excerpted independent transcript © Brice Dudout with Claude (Anthropic), 2026, CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/). JACAR archival photos are excluded from package. The predecessor artifact is `sun_wenmi_round15.zip` in Library.

No Chinese June plaintext recovered. See `WENMI_ROUND16.md`.
