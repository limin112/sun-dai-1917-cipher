# 孙中山—戴季陶1917年六月密电：跨 Agent 研究交接包

**版本**：2026-10-13，基于已归档最新 Round17。**状态**：两封目标中文新明文0字；完整密钥未发现。请勿向用户宣称已破译。

## 目标 / 唯一任务
JACAR **B03050090200**：帧**0509**，1917-06-24，孙中山（上海）→戴季陶（东京）；帧**0511**，1917-06-29，戴季陶（东京）→孙中山（上海），包括两张电报纸。目标是取得可校验中文全文、确定具体历史密码本/版本/密钥/编码与控制码规则、逐字重加密一致、获得独立材料交叉核验。**不能**用1916-04-03汕头、1916已解“文密”线路、1917年3月或5月内容替代。六月电报自身没有明确“文密”或“Cg”前缀，“文密”暂是项目名称，不能直接推定同表同钥。

## 核心发现和结论状态
- 已获取Brice Dudout公开的0509/0511两张**JACAR扫描复制图**，不是本项目直接获取的JACAR官方原始PDF；因权利限制**不在ZIP中重新分发图像**，请在 `SOURCES_AND_ACCESS.md` 点击源链接。两份公开独立转录有疑字，不得按结构评分静默修正。
- 0509独立盲读8个10字母词（共80字母），第二词摩斯`ä`读法可能有`ek`、`aa`、`rt`拼接，另有独立视觉变体；不唯一。0511独立盲读29个密文词，合计282字母，分两张纸172与110。存在11字母和9字母词，**不可强补或删字符**。`kohokycuee`旧读与`kohokycuce`新读有冲突；另`damowmhosy/damoumhosy`等未定。
- 第17轮采用三段四字母格点相位(0,0,2)发现 `cafe` 和 `mupo` 分别在0509、0511a、0511b各一次；另`kige`和`mafy`重复。8对重复、7对跨段；有词内双字母重排随机检验与独立1917年3月历史正对照，**统计显著只是探索性结构信号**，相位和假设均事后发现，并非破解。
- 0511总282字母模4余2；固定每4字母编码1汉字且绝无其他码类的简单模型与长度不符。页间可能额外双字母控制码/遗漏/其他分组，也可能统计相位选择效应。扫描图上未能确认确切漏码。
- 历史第64号表20×5共100格，博物馆图和论文样例确认，但按表原样六月有无法解释的双组。**不能推定这就是六月密钥**。1916 G0/Y0与1917年3月已解表也不适用于六月。
- 3月23/25/26研究者Daniel Bourdeau使用固定形状20×5表的旋转/反转/元音列变换，先枚举57,600个表结构候选（另对偏移做评分），之后以25/26两封留出验证；已解文本仍有局部缺失/歧义。其可重复程序链接见来源文档。该案例用于算法历史正对照，不是六月译文。

## 验收标准
仅当同时有：确切码本实物或特定书籍版次/表格规则；所有异常字符的原图依据和完整校改日志；每个字/控制码逐位从译文重加密回冻结密文；没有用于拟合的独立同钥电报或同文明文留底；所有中间文件/负结果/校验记录，才能称得到中文。单向解码、语言模型通顺、显著随机对照、任意字母换名/别名都不够。

1. 从JACAR官方取帧0509、0511高分辨原图，独立盲校所有疑字，重点0511第一页末尾/第二页开头以及11/9字母词和0509特殊字符。保留并列候选和影像位置。
2. 寻找同线路1917年6—7月其他密报或中文收发留底；检索戴季陶赴日调查报告。
3. 取得党史档案 yiban050/5.3（1913《仁密》）、yiban333/2.2（64号）、yiban050/1.2（1918日文密码）完整原件，尤其凡例、附表、页眉私填数字、换密条；爱知大学1923胡汉民致藤瀬书简藏品270/整理138/24-6。
