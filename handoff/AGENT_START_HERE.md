## 先读与复现

1. 从仓库根目录阅读 `rounds/round19/WENMI_ROUND19.md`、`rounds/round19/README.md` 和本目录 `RESEARCH_STATE.md`。Round 18 报告仍是历史记录，其断言须结合 Round 19 修订阅读。
2. 输入在 `data/ciphertexts.json`（raw / analysis_variants）、`data/independent_witness.json`、`data/morse_and_page_observations.json`，不可覆盖。R18 的 B/D 是另行校改的分析读本；D 相对冻结盲读有 4 处改动。
3. 运行 `python3 -m unittest discover -s rounds/round19/tests -v`，再按 Round 19 README 复现。代码从自身路径定位输入，结果带 SHA-256 和假设说明。
4. 读取 `rounds/round19/results/` 和 `sources/`，检查统计对照采用哪个读本、哪个参考序列、哪些候选，不能只看 p 值。

## 本轮关键边界

- 元音开头字母对删除后，R18 校改读本可产生 20 + 67 码；这是候选切分，尚未证明历史虚码规则。独立原始盲读的异常字符不得吞掉、补齐或按得分改字。
- R18 随机删除从方向归一化序列抽样，可作条件对照；它不是原始 fixed-pair 序列对照。R19 并列比较，并检查词内位置压缩及有限候选选择的影响。任何校正都不覆盖全部历史探索。
- 约 440 比特 / 每字 5 比特的唯一解距离估计，依赖表族、密钥先验、语言冗余和无噪声等假设；不能把约 88 当成保证可解或不可解的阈值。
- 搜索阴性只覆盖已运行读本、模型、参数和预算。单个历史正对照成功不能证明对六月任何同族表都必能求解。
