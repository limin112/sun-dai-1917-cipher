Round 14 · 2026-10-10

y 双角色的可复现结构检验

结构发现

本轮要点

  • 假设：a/e/i/o/u 只作元音，其它只作辅音，y 可兼两者，两字母组 CV/VC 皆可。
  • 0509 35/35、0511 124/125（含8字母词 140/141）合法；唯一例外 kohokycuee 的 ee。
  • 词内随机重排 10,000 次对照 p<0.0001；1916-04-03 汕头电报正对照 84/84。
  • Kuzuoglu (2018) 指出 1913《仁密電碼本》等具名码本（党史馆 yiban050/5.3），“文密”可能也是具名私密本。
六月电报已验证译文仍为 0 字。以下为原始报告全文，结论以更高轮次为准。

报告全文

研究日期：2026-10-10（Asia/Shanghai）。目标始终为 JACAR B03050090200：1917-06-24 帧0509 孙中山→戴季陶及 1917-06-29 帧0511 戴季陶→孙中山。本报告不将1916汕头电报或任何五月电报当作本题译文。

验收状态：六月可验证新明文 0 字；确切密钥 0 把；六月两帧原始影像仍未取得；image_verified=false。 本轮发现的是可复核的字母结构约束，不是译文，也不是已经证实的历史码本。

1. 衔接和来源

本轮首先核对会话可用的 WENMI_ROUND13.md 和 sun_wenmi_round13.zip；Round13 已将爱知大学实物上的五码例子与 Kuzuoglu (2018) 全部100格第64号数字表验证一致。完整冻结源从 Round13 ZIP 精确提取到 input/ciphertexts.json，SHA-256 620e469ec26d6534df2dbad0553d79844f1d9df8e68e47a95194a1c0563a8136。原始公开转录 raw_june_notes 与研究者程序输入 analysis_variants 原样分栏保留。原件尚未校验，绝不悄悄修正 hutadyny(y)go、mevecafema(u) 或短词。

相关公开档案与材料：

  • 日本 JACAR B03050090200、B03050090000。本轮 web PDF URL 仍不能访问、元数据URL 返回403；容器请求出现DNS异常，未读取任何新的六月原件像素。
  • Daniel Bourdeau 的公开研究/转录（版本仍将六月目标标记 not read），以及 9月研究页。
  • Kuzuoglu (2018), Chinese cryptography。论文印出了第64号表（20个辅音行 xyzbcdfghjklmnpqrstv × 5个元音列 uoiea），并在脚注5确指1913年4月 仁密電碼本，PHI 一般档案 yiban050/5.3，以及后期 誠密、東密、雍密 等专名码本。这是独立的历史命名/藏品记录，使“文密是某一具名的私人中文密本”成为有实际类比的候选；但没有找到文密同名字册或目标密钥。
  • 爱知大学展品公开图：https://edu.aichi-u.ac.jp/toa/collection/gallery02/19EU5116_RT8.jpg（前轮已核对，不冒称本轮重新取得）。

2. 本轮新检验：让 y 同时承担两种位置角色

已知第64号历史表将字母 y 放在辅音行，而公开研究将1917六月的若干 y 判作第六元音。两种历史/转录迹象此前分别出现，但过往模型固定 y 为一类，出现 ac/cy/ya 奇环矛盾。于是测试预先明确定义的扩展句法模型：

  • 普通元音 a,e,i,o,u 只能是元音。
  • 普通辅音 b,c,d,f,g,h,j,k,l,m,n,p,q,r,s,t,v,w,x,z 只能是辅音。
  • y 可当元音，也可当辅音（例如 my 可解释 m＋元音y，ya 可解释辅音y＋a）。
  • 单位为两个字母，词内从首字母固定分组；两种顺序都允许（CV/VC）；yy 也允许，ee 必不允许。

代码独立用两个实现验证：直接谓词 dual()（主脚本），及穷举全部允许字母对（独立脚本，词长为8和10均保留）。这只是字母组合可能性，未确定哪个组合对应 00–99，也没有生成任何经认可的中文。

3. 实测结果与独立否证控制

冻结分析输入 用于保守主检验的10字母词 双字母槽位 y只作辅音（5元音） y只作元音（6元音） y双角色
1917-06-24 0509 7 35 30/35 34/35 35/35
1917-06-29 0511 25 125 103/125 118/125 124/125

对不填补字母且长度为偶数的所有词另外独立复核：0511 140/141（含四个完整8字母词，之前已报告但曾被排除在10字母测试之外）。唯一不合上述特定语法的槽位：0511第7个词 kohokycuee 的第5对 ee。0509完整10字母词35/35；其9字母词 vemucayri 保留原样，仅可在不改变文本前提下记录前四对 ve/mu/ca/yr 都符合，最后 i 孤立，不得将这四对当作可靠的原始完整码词。若仅做候选前缀展示，0509计39/39；但保守统计仍应使用35/35。

随机对照：每封电报将每个被使用的偶数字母词内部随机重排10000次（保留词的长度和各词字母多重集，打乱相邻关系），每轮同样计数双角色合法槽位。0509（10字母词35槽）平均21.93，最多31，真实35；0511（8/10字母词141槽）平均90.88，真实140，模拟最高值未达到真实值，两者 Monte Carlo 加1尾概率均 <0.0001（仅针对预设的这一重排零假设；后验提出模型，不作形式上发现概率/密钥概率）。

历史算法正对照：1916-04-03早已公开的汕头转录仅作为代码测试数据，扩展句法对其所有偶数字母词 84/84（其中16个10字母词80对，另8字母词4对）全合法；这绝不算新的目标电报成果。数字映射正对照独立将历史第64号表的 時機大可為 与 明密碼電報 合计 10/10 已发表四字母—四数字示例精确回算一致，证明主脚本表的数字实现未读错文献，而不能证明其适用于六月。

疑读敏感性：在保持两类显式版本独立的条件下，hutadynyyg→hutadynygo 或保留可选 y 的11字母版本；0511 都仍恰好 140/141，失败始终为 kohokycuee 末尾 ee；mevecafema 加可选 u 形成11字母词后，0509逐词已有的完整前缀仍都符合，但新增一个无法判定的单字母尾巴。详见 results/variant_sensitivity.json。

4. 数字层小试验：没有取回秘密钥匙

以2018文献真实第64号100格表作为历史可重现外层示例，增加一个未在史料确认的规则：当 y 跟普通辅音同对时，y 可依次替代五元音中的任一元音；当 y 跟普通元音配对时，沿用历史表里 y 自身为辅音行的定义。让两个顺序相反的拼写反查同一双数字。

这能让0509原35槽全部转成候选两位数字、0511原125槽除ee外124槽转成候选两位数字；然而 5种 y 别名均可做到，且未经核实其任何一把是目标实际使用的表。下游四位数字由于短词位置、单独一对缺口和1917真实中文码本版次缺失，不具备整体回转/中文校验条件。全部5种连续数字候选仅保留在 JSON，绝不编造中文释读。

5. 证据级别与下一轮有用动作

发现的“y 既可能在辅音位，也可能在元音位”使观察到的160个十字母词双组中，只有1组不能按此统一句法解释；含完整8字母词则为175/176。结构上的大改进来自放宽符号角色，并非找到真实密钥。ee 有可能是原图误读、特殊替代对、换码/边界，或者直接反驳该模型，均无原始影像证据。不能静默修改它。

优先核实JACAR 0511 第7词 kohokycuee 字母的原始图（尤其末两位）及0509的 vemucayri 缺口，然后取得 PHI 1913 仁密電碼本 yiban050/5.3 的档案目录和版式以核对“文密”是否也指一部具名中文密本；继续追 PHI yiban333/2.2 / yiban050/1.2，以及爱知大学1923胡汉民书简、1916 JACAR 文密 0416。若到手实际表/明密留底，再做结合相位、词长和坐标/码本版本的约束解码。不能凭语法可行、模拟 p 值或四位数字有中文查表项来宣称破译。

6. 复现和保存

标准 Python 3，零第三方依赖：

python dual_y_real_table.py
python extended_independent_check.py
python variant_sensitivity.py
  • input/ciphertexts.json：原样冻结的 Round13 输入，两套六月读法保留并打 image_verified=false。
  • dual_y_real_table.py：原刊第64号100格映射＋正对照＋对原版10字母词10000次重排＋五种y别名的候选数字。
  • extended_independent_check.py：独立穷举字母对/保留8字母词的验证与10000次重排。

  • results/dual_y_results.json、results/extended_independent_results.json、results/variant_sensitivity.json：完整结果。
  • results/*.log：实际运行记录。
  • sources/README.md：访问层级和馆藏号。
