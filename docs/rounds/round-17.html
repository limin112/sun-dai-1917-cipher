两枚三重重复码、页界相位与摩斯 ä 的穷举

结构发现

本轮要点

  • 相位 (0,0,2) 下 cafe 与 mupo 在 0509 / 0511a / 0511b 各出现一次；8 对重复、7 对跨段。
  • 词内重排对照 p≈2×10⁻⁵；1917 年 3 月已解电报作检测器正对照（p≈1.7×10⁻⁴）。

报告全文

日期：2026-10-13。 目标严格为日本 JACAR B03050090200：1917-06-24 帧0509（孙中山上海→戴季陶东京），及1917-06-29 帧0511（戴季陶东京→孙中山上海）。不得以1916年已经发表的“文密”、汕头电报、1917年3月或任何5月电报替代本题。

状态：尚未获得一字经验证的六月中文译文（0 字）；数字表、私人码本或书本坐标密钥均未找到。 本轮进展是新的可重复结构证据，不是解密。源图为 Brice Dudout 公开的 JACAR 扫描复制图、不是本轮重新从 JACAR 官方 raw PDF 获取。独立人工转写中保留全部疑读。

1. 衔接及冻结

先由 Library /wenmi_research 列目录，确认最新确为 Round 16 的 .md 和 .zip，再读取原报告与ZIP。Round16冻结的input/ciphertexts.json原封不动复制，SHA256仍为620e469ec26d6534df2dbad0553d79844f1d9df8e68e47a95194a1c0563a8136；raw_june_notes和analysis_variants两个层次不更改。第二证人的input/independent_witness.json也原字节复制，SHA256 1a7362cd229a0a407eb171dec7ba32572763cfb03c0d09a98caedd7370db8ac1；不得当作唯一核定原文。

本轮另独立读取 Daniel Bourdeau 公开的1917年3月23、25、26日已破译孙戴电报作为正对照，源码 GitHub blob SHA c93f061da84d11ea3b2941dde78c970fe801df88，收进 input/march_positive_control.json。这三封只用于衡量检测程序是否能识别真实同密钥码流，不参与六月拟合、也不算目标译文。爱知大学64号表和已知1916 G0/Y0仍与六月区分。本轮未找到新可用历史密钥。

2. 真正新增的结构线索：mupo也重复三次，而且跨两封六月电报

Round16曾注意 cafe、kige、mafy。本轮用全部 40+141个二字母槽机械枚举完整四字母单元，不挑中文语义，额外发现此前未标明的mupo三次重复。采用0509从第0字符配四字码、0511a从第0字符配四字码、0511b从第2字符配四字码（同Round16提出的页界相位，明确标为数据后选择）：

四字母码 0509 0511a（前页） 0511b（后页） 结构备注
cafe 1 1 1 0511a一次跨电报词界
mupo 1 1 1 0509、0511b均跨词界，0511a在首词开头
kige 0 1 1 两页各一次
mafy 0 0 2 后页一次跨词界

因此完整三段的相同四字母码的重复配对数为 C(3,2)+C(3,2)+C(2,2)+C(2,2)=8，其中跨段重复配对共 7。若强制三段均第0字符配四字码，重复配对共2、跨段共2（仅cafe、mupo在0509与0511a重合）。不等于这些四字母一定代表单个汉字；只有它们恰好落在真实单字/单码边界上时才有此含义。 results/phase_repeat_analysis.json记录每一处0起算字符偏移和跨词情况；不以手工挑选某个词代替完整频次。

3. 新算法与“不能凭巧合宣布破译”的独立校验

仅作密码结构检验，不给每个双字母分配数字，更不生成中文。分别对每个10字母/8字母/奇数长度印刷词，在词内随机重排完整双字母组，奇数字母尾保留原处。它保持每个词的长度、双字母使用频率和若干边界限制，但打断哪些两个双字母会相邻；正是检验相同四字母单元是否超出这一特定零假设所需。每次乱序都重新优化0511b的0/2相位；并作独立更宽的三个分段的2×2×2=8种相位都搜索，而不只在真密文上找最好一组。

  • 已知正对照（1917年3月23/25/26，真的共享一把已解密钥）：在独立转录上不校正笔误，从相位0统计到5组跨电报重复四码；12000次词内乱序只有1次达到或超过观测（p_plus1 ≈ 0.0001667）。这说明检测程序至少能在一个独立已知历史正对照中找到并检出真实结构；并非只对本题碰巧灵敏。只验证“重复结构检测”方法，绝不验证六月明文或特殊方案。
  • 六月、0511b在0/2两相位取较优：50000次词内乱序，没有一次达到观测的8组重复配对或7组跨段重复配对，p_plus1=1/50001≈0.0000200。另一种零模型（整页内打乱双字母，三段各自保留使用频数）12000次重排有1次达到，p_plus1≈0.0001667。零模型不同，结果不能混成一个“真实密码概率”。
  • 更保守的8相位检验：三个分段都允许从字符0或2开始形成四码，每次12,000次零对照都同样尝试全部8组合。观测最大为cafe与mupo这两个四字母组同时出现在三段，最佳相位恰为 (0,0,2)，且跨段匹配7。零对照没有一次在“三段共同模式数、再比较跨段匹配数”的字典序上达到观测；p_plus1≈0.0000833。

重大统计限制：相位偏好、cafe等线索已经在Round16及外部学者分析中被看到，本轮并非对完全未知数据的一次先验注册发现。上述p值只检验我们声明的随机对照与8种相位，不能涵盖前16轮海量探索的多重选择，也不能作为同钥匙/同汉字或译文成立的概率。这一点很重要：强结构信号不等于破解。

4. 本轮新硬约束：0511长短词与页界在“纯四字码”假设下存在未解释的2字母残差

独立证人0509共8词×10字母=80字母 = 20个四字码。0511a有18个词、172字母（模4余0）：其中11字母1词、9字母1词、8字母4词、其余12词10字母；0511b有11个完整10字母词共110字母（模4余2）。全0511 282字母=141组双字母，模4余2。

因此，假如原信息只有每四个拉丁字母恰好一个汉字且没有任何别的码类/填充，那么现有0511全部字母长度与该模型不相容——必须有合计2字母的净增减才达到4的倍数；一次单字母插入或删去不能解决。也可能有合法的2字母短码、页首尾控制码等。不能因此删除、增补任何字母。

而且，若0511a原样172字母、全电报是不断开的纯四字码，0511b自然应从相位0开始；重复结构却偏好0511b相位2。可能涉及页界丢/增一整个双字母、合法其它码类、明密混合、错误分组或探测器事后择相偏差。本轮没有在图像上发现能独立确定哪一种成立的证据。

有一个容易诱人的猜法是将0511a首个11字母词muposacyobe和第三个9字母词catyidohe各删掉最后一字母e，令总长280并产生另一种页界条件。但这是未经档案支持的篡改，程序明确以反事实计算：这项双删方案会令预选相位2下跨段重复配对由7减少到4，反而削弱当前重合。它不是本轮校定结果，且未纳入冻源。

5. 另一个可复算的原始信号：摩斯 ä 不是唯一的 “e+k”

0509扫描复制图第二个词的争议记号有一个摩斯 ä (.-.-)的读法。若该信号是由两枚不加停顿的普通A–Z摩斯字母组成，将所有26²两字母组合机械匹配，恰好有三种拼法：

  • e+k（. + -.-）→ vemucekyri；双角色y配对语法全部合法。
  • a+a（.- + .-）→ vemucaayri；也全部合法。
  • r+t（.-. + -）→ vemucrtyri；含 cr，不符合该简单双角色语法。

这纠正了“摩斯ä必然等于e+k”的过强说法。仅凭元辅拼写只能留下ek/aa两个，不足以唯一恢复字母，更谈不上解密。 而独立读者的vemucicyri是另一种视觉抄录可能性，与上述摩斯信号假设必须分开保存。可见图中是否刻意写了独立的ä字母、是否使用不同摩斯惯例仍开放。

6. 电报表自带的发送词数：对“漏了整词”的独立检验

从前轮取得且本轮再查看的扫描复制图看：0511“Words:32”，按独立读者的29个密文词、收报地址两个明文词Sunyatsen Shanghai、末尾明文署名Tai恰合32；0509“Words:14”，8个密文词+明文署名Sunwen+地址按5个收费词读取也可合14（地址分词仍为暂定）。这提供了整词数量完整性的独立旁证，但没有证明词内某个字符正确或不缺字。0511连一长一短的首行异常词均计入29词，不能擅自凭“10字母标准”删掉短词或增添整词。
